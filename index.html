Prepare & flash samples

Build a 512 KB sample image (16 × 32 KB), download it, and write it to your Dtronics programmer over USB serial in Chrome or Edge — no desktop install required.

Web Serial is not available. Please open this page in Google Chrome or Microsoft Edge on a desktop computer via the HTTPS site (not a local file).
This tool must run in its own browser tab. Serial / USB access cannot work inside an embedded frame. Open the programmer from the Dtronics site using “Start Web Programmer”.

    Help

    1. Open this page in Chrome or Edge (desktop, HTTPS).
    2. Add up to 16 sample files (max 32 KB each) — select or drag and drop.
    3. Optional: Download combined file for a 512 KB backup.
    4. Connect and choose your Dtronics USB serial programmer.
    5. Send combined file, or Open file and send an existing 512 KB image.

    More information: https://www.dtronics.nl/dt-drum-expansion
